Reduced-scale pediatric/neonatal instrument set

Shorter, finer-gauge versions of instruments already in the catalog (Metzenbaum scissors, Kelly forceps, needle holders), adapted to neonatal and pediatric anatomy.

How it is used

Dissection and hemostasis in neonatal and pediatric surgery, where adult instruments are disproportionately large.
