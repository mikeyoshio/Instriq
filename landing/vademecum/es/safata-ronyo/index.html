Bandeja de riñón (riñonera)

Recipiente poco profundo con forma curvada de riñón, de acero inoxidable o plástico de un solo uso, con un borde rebajado para adaptarse al cuerpo.

Cómo se utiliza

Recoge gasas sucias, residuos o especímenes durante una intervención o procedimiento, y también se utiliza fuera de quirófano para recoger vómitos u otros fluidos.
