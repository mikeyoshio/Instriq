Estilete de fístula anal

Sonda metálica fina y maleable de punta roma, recta o curva, a veces con un ojo para pasar un hilo.

Cómo se utiliza

Seguir el trayecto de una fístula desde el orificio externo hasta el interno.

Consejo clínico

Nunca se fuerza: si no avanza, se crea una falsa vía. A veces se inyecta agua oxigenada o azul de metileno para encontrar el orificio interno.
