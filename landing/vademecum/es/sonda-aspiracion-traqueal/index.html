Sonda de aspiración traqueobronquial

Catéter blando, flexible y de un solo uso, con un orificio de control de succión en el mango, diseñado para introducirse dentro de un tubo endotraqueal o de traqueostomía hasta los bronquios principales.

Cómo se utiliza

Se utiliza para aspirar secreciones de la vía aérea inferior en pacientes intubados o traqueostomizados, a diferencia de las cánulas rígidas (Yankauer/Frazier) ya catalogadas, reservadas para la cavidad oral y el campo quirúrgico abierto.

Consejo clínico

El sistema de aspiración "cerrado" mantiene el catéter protegido dentro de una funda conectada al circuito del ventilador, evitando desconectarlo y perder la PEEP durante la aspiración.
