Cesta/bandeja perforada de instrumental

Bandeja rígida de acero inoxidable o malla metálica, perforada o de entramado abierto, dimensionada para organizar un set de instrumental.

Cómo se utiliza

Mantiene organizado y contabilizado un set de instrumental durante la limpieza, la esterilización (deja pasar el vapor o el gas a todas las superficies) y el almacenamiento.

Consejo clínico

Existe en muchos tamaños estándar para encajar con diferentes contenedores de esterilización y cámaras de autoclave.
