Catéter venoso periférico

Cánula corta de plástico montada sobre una aguja metálica guía, que se retira una vez puncionada la vena periférica y deja solo el tubo flexible dentro del vaso.

Cómo se utiliza

Es la vía de acceso vascular más habitual para administrar fluidos, fármacos intravenosos o contraste, cuando no se necesita un acceso venoso central.

Consejo clínico

Su calibre, identificado por un código de color según la escala Gauge, se elige según el ritmo de infusión previsto; a menudo se conecta a una alargadera, una llave de tres vías o un tapón de heparina para facilitar el acceso intermitente.
