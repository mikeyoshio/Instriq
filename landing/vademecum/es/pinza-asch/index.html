Pinza de Asch

Pinza larga con dos ramas estrechas que se introducen una en cada narina, diseñada para agarrar y movilizar el tabique nasal y los huesos propios de la nariz.

Cómo se utiliza

Se utiliza en la reducción de fracturas nasales y septales, aplicando una fuerza de tracción y elevación para reposicionar el hueso y el cartílago desplazados.

Consejo clínico

La introducción simétrica de las dos ramas es esencial para evitar lesionar la mucosa septal durante la maniobra de reducción.
