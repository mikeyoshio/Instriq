Calibrador de grapadora circular

Instrumento reutilizable de acero inoxidable con una cabeza ovalada o redondeada en tamaños graduados (p. ej. 25/29/33 mm), que se introduce por vía transanal para medir el diámetro de la luz rectal o cólica.

Cómo se utiliza

Se utiliza antes de disparar una grapadora circular para una anastomosis colorrectal (p. ej. tras una resección anterior baja) para elegir el tamaño correcto de cabezal o carga.
