Sistema de control de temperatura dirigido

Dispositivo que, mediante mantas o catéteres intravasculares con circulación de agua, mantiene la temperatura corporal del paciente en un valor objetivo preciso durante horas o días, con retroalimentación automática desde una sonda de temperatura.

Cómo se utiliza

Se utiliza tras una parada cardiorrespiratoria recuperada para evitar la fiebre y, en algunos protocolos, inducir una hipotermia leve-moderada, con el objetivo de reducir el daño neurológico secundario.

Consejo clínico

A diferencia de una manta de calentamiento pasivo ya catalogada, este sistema controla activamente tanto el calentamiento como el enfriamiento dentro de un margen muy estrecho.
