Aguja espinal (intradural)

Aguja fina de calibre pequeño, con bisel cortante (Quincke) o punta de lápiz atraumática (Whitacre/Sprotte), utilizada para puncionar el espacio subaracnoideo.

Cómo se utiliza

Se utiliza para administrar anestesia raquídea (intradural) inyectando anestésico local en el líquido cefalorraquídeo, y también para punciones lumbares diagnósticas.

Consejo clínico

Las puntas de lápiz (Whitacre/Sprotte) reducen la incidencia de cefalea post-punción dural en comparación con las agujas de bisel cortante Quincke.
