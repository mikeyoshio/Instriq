Gancho de Gass

Gancho oftálmico de titanio con una pala aplanada y un orificio cercano a la punta, diseñado para enganchar y elevar los músculos rectos extraoculares.

Cómo se utiliza

Se utiliza en la cirugía de cerclaje escleral (scleral buckling) para reparar el desprendimiento de retina regmatógeno: permite aislar y elevar cada músculo recto para pasar por debajo suturas de tracción y guiar la banda de cerclaje sin lesionar los tejidos adyacentes.

Consejo clínico

El orificio cercano a la punta permite enhebrar directamente una sutura de tracción, manteniendo el músculo sujeto mientras se coloca la banda.
