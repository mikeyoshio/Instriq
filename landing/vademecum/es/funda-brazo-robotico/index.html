Funda estéril de brazo robótico

Funda de un solo uso específica de cada sistema que cubre el brazo y lleva integrado el adaptador estéril donde se conectan los instrumentos.

Cómo se utiliza

Mantener la esterilidad del brazo y hacer de barrera entre la parte no estéril del robot y el instrumento estéril.

Consejo clínico

Se coloca antes de acercar el robot a la mesa. Si el adaptador no encaja bien, el sistema no reconoce el instrumento.
