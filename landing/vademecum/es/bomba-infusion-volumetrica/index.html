Bomba de infusión volumétrica

Dispositivo electrónico que impulsa y controla con precisión el ritmo de infusión de un fluido intravenoso, epidural o enteral, programable en mL/h, con alarmas de oclusión y de fin de infusión.

Cómo se utiliza

Se utiliza para administrar de forma controlada sueros, fármacos intravenosos, analgesia epidural continua o nutrición enteral, cuando se necesita una precisión que un goteo por gravedad no garantiza.

Consejo clínico

La variante de jeringa se utiliza para volúmenes pequeños y fármacos de margen terapéutico estrecho (p. ej. vasoactivos); varios módulos pueden apilarse en un mismo soporte para pacientes polimedicados.
