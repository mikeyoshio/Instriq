Hyfrecator (electrodesecador)

Dispositivo de electrocirugía monopolar de baja potencia que genera una corriente de alta frecuencia aplicada mediante un electrodo fino de punta de aguja o bola.

Cómo se utiliza

Se utiliza para la electrodesecación y electrocoagulación de lesiones cutáneas superficiales (angiomas, verrugas, queratosis) y para la hemostasia puntual durante biopsias.

Consejo clínico

A diferencia del electrobisturí quirúrgico, trabaja a potencias muy bajas, lo que lo hace adecuado para procedimientos ambulatorios menores bajo anestesia local.
