Parche de e-PTFE para hernia diafragmática congénita

Lámina de politetrafluoroetileno expandido, de grosor variable, utilizada para cerrar defectos diafragmáticos grandes que no permiten un cierre primario; distinta del injerto vascular de e-PTFE ya catalogado, que es un tubo para vasos, no un parche de tejido blando.

Cómo se utiliza

Reparación de una hernia diafragmática congénita (de Bochdalek) cuando el defecto es demasiado grande para una sutura directa.

Consejo clínico

Le falta la elasticidad suficiente para acompañar el crecimiento del niño, lo que provoca una rotura precoz de los puntos y recidiva en hasta un 28-50% de las series; se prefiere el cierre primario directo cuando es posible.
