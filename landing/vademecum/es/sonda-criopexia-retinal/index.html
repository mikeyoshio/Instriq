Sonda de criopexia retinal

Sonda metálica conectada a una unidad de refrigeración (CO2 u óxido nitroso), con una punta que alcanza temperaturas muy bajas de forma controlada.

Cómo se utiliza

Se utiliza en cirugía de desprendimiento de retina para crear una adhesión coriorretiniana alrededor de desgarros retinianos mediante congelación controlada.

Consejo clínico

La aplicación debe controlarse bajo visión oftalmoscópica indirecta para evitar una criocoagulación excesiva que podría favorecer la proliferación vitreorretiniana.
