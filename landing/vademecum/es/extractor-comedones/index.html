Extractor de comedones

Instrumento metálico delgado, con un pequeño anillo u orificio en cada extremo, diseñado para aplicar una presión controlada alrededor de una lesión cutánea.

Cómo se utiliza

Se utiliza para extraer comedones, milium y tapones queratósicos, aplicando una presión uniforme que expulsa su contenido sin traumatizar la piel circundante.

Consejo clínico

Conviene incidir previamente la lesión con una aguja fina cuando la capa córnea es demasiado resistente para que el extractor funcione por sí solo.
