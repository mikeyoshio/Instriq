Nefroscopio

Endoscopio rígido (o híbrido rígido-flexible), con vaina y canal de trabajo, diseñado para introducirse por un tracto percutáneo hasta el sistema colector renal.

Cómo se utiliza

Permite visualizar directamente los cálices y la pelvis renal, y el paso de instrumentos (litotritores, pinzas, cestas) para fragmentar y extraer cálculos durante una nefrolitotomía percutánea (NLP).
