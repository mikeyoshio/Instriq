Sonda de Foley

Catéter flexible de látex o silicona con dos o tres luces: una para drenar la orina y otra para inflar un balón de retención en la punta una vez dentro de la vejiga.

Cómo se utiliza

Se utiliza para drenar la vejiga de forma continua (retención urinaria, control de diuresis, incontinencia, postoperatorio); la versión de tres vías permite también realizar lavados vesicales continuos.
